# NESdev Reference Snapshot

This directory contains attributed English-language snapshots of NESdev Wiki
pages used as primary hardware and format references during reconstruction. The
pages are reference inputs, not project-authored architecture, release policy,
or a substitute for the task-oriented documents linked from `docs/index.md`.

Each snapshot retains its source URL near the beginning of the file. Files are
grouped by reference topic; `fds.md` owns the Famicom Disk System format page.
Refreshes must preserve attribution, remain reviewable as imported material,
and must not silently change project claims. Project conclusions and current
contracts belong outside this directory and cite the relevant snapshot when
needed.

The licensing status of imported reference material is recorded in
[`../licensing.md`](../licensing.md). The machine-readable documentation
inventory treats this entire directory as one vendored boundary and checks that
every content snapshot remains attributed.
